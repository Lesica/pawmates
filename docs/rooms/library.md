# Комната: Библиотека

🎯 **Челлендж-комната.**

---

## Идея

Головоломки с книгами. Тип головоломки — открытый вопрос:
- Word puzzle (find the missing word)
- Sequence puzzle (расставь страницы по порядку)
- Visual puzzle (картинки в книгах)

## Награда

Зверёк становится **«учёным»** — новая шапочка / очки / поза для зверька в стартовой комнате.

## Связь с Bond

- Каждая решённая головоломка: +100 Bond + cosmetic award.
- Каждая попытка (не решённая): +20 Bond за саму попытку. Не наказываем.

## Когда открывается

При накоплении 6,000 Bond.

## Подарки зверька из Библиотеки

- Старая закладка
- Сухой цветок (между страниц)
- Маленькая бумажка с рисунком
- Перо (от орла из иллюстрации; немного абсурдное)

## Визуальный стиль

Тёплая комната с книжными полками от пола до потолка. Фронтальный вид. Лестница на высокие полки. Лампа с зелёным абажуром.

Палитра: тёмно-коричневая, бордо, золотая.
