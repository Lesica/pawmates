# Комната: Двор

⚡🌿 **Социальная комната будущего.**

⚠️ **Самая сложная и опасная комната.** Реализация — последняя по очерёдности.

---

## Идея

На старте — **пустой двор**. Зверёк может выйти, погулять, увидеть деревья, лавочку. Это и есть начальная версия — никаких других зверьков.

По мере роста базы пользователей — появляются зверьки **с живыми хозяевами**. Можно подойти к чужому зверьку, познакомиться (механика «обнюхивания»).

Если оба хозяина одобряют контакт — открывается совместное задание для двоих.

---

## Критические safety-нюансы

⚠️ Эта комната — **самая высоко-рискованная** в плане безопасности. Социальный слой с геолокацией = потенциал сталкинга, харассмента, abuse. Один публичный инцидент = смерть продукта.

См. `../00_pillars.md` (через расширение). Перед запуском **обязательно**:

### Минимум обязательных safety-фичей

- [ ] **Опт-ин «только женщины»** — режим где видишь только женщин (через ID-верификацию или фото с жестом)
- [ ] **«Не показывать что я гуляю одна»** — режим скрытности
- [ ] **Hard timeout** — если другой игрок несколько раз приближается без согласия совместного задания, блок
- [ ] **Quick-block + report** — без объяснений, два таппа
- [ ] **Размытие позиции до района** — никогда точная координата
- [ ] **Никакого voice chat** — только текст, только модерируемый

### Регуляторные требования

- GDPR (EU)
- DSA (EU)
- ФЗ-152 (РФ)
- COPPA (US, если несовершеннолетние)

Перед запуском комнаты — **обязательная** privacy threat model. Без этого не запускать.

## Когда открывается

При **высоком** Bond — 10,000+. Это намеренно поздно — игрок к этому моменту уже глубоко связан с зверьком, **готов** к социалке.

## Визуальный стиль

Дверь из стартовой → выходишь во двор. Открытое пространство, дерево, лавочка. Перспектива немного более глубокая чем в комнатах.

Зверёк бегает свободно, можно тапнуть на земле — он туда пойдёт.
