# PawMates — документация проекта

Здесь хранятся **идеи, принципы, дизайн-решения и контекст**. Не код — для кода есть сам репозиторий.

## Карта

### Корневые документы (читай в этом порядке если впервые)

- **[00_pillars.md](00_pillars.md)** — неизменяемые принципы. Если решение их нарушает — оно нам не подходит.
- **[01_architecture.md](01_architecture.md)** — метафора комнат. Главный архитектурный концепт.
- **[02_starter_room.md](02_starter_room.md)** — дизайн стартовой комнаты подробно.
- **[03_progression.md](03_progression.md)** — как зверёк растёт, петля Bond.
- **[04_visual_style.md](04_visual_style.md)** — аналоговая графика, рефы, художественный workflow.
- **[05_atmospheric_compass.md](05_atmospheric_compass.md)** — критерии «брать решение» / «выкидывать».
- **[06_open_questions.md](06_open_questions.md)** — нерешённые вопросы на потом.

### Папки

- **[rooms/](rooms/)** — по файлу на каждую идею комнаты. Сейчас живая только `starter.md`, остальные — задумки.
- **[art_refs/](art_refs/)** — сканы Алёниных скетчей зверьков, мудборды, референсы. Бумага → телефон → сюда.
- **[brainstorms/](brainstorms/)** — сырые выгрузки brain-сессий (не разобранные по тематическим документам).
- **[JOURNAL.md](JOURNAL.md)** — дневник развития: что попробовали, что зашло/не зашло, ага-моменты.

## Правила работы с документами

1. **Каждый файл = одна тема.** Не сваливать всё в один файл.
2. **Изменения через git** — каждое пополнение = коммит. Через год будет история того как игра созревала.
3. **Brainstorms сохраняем как есть**, но потом **разносим** содержимое по тематическим файлам. Пусть исходник останется в `brainstorms/` для истории.
4. **Не редактируем `pillars.md` без обсуждения** — это якоря, которые мы намеренно держим неизменными.
