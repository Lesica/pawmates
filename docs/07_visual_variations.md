# Визуальные вариации зверя — насколько дорого менять

Документ от 3 мая 2026. Записал в ответ на вопрос Алёны: «насколько сложно менять цвет / форму / позу кота, нужно ли рисовать 10 вариантов?»

---

## Краткий ответ

**Зависит от того что меняем и какой формат рисунка.**

---

## Уровень 1. Цвет шерсти, цвет глаз, цвет пятен

### SVG-вариант (то что сейчас)

**Очень дёшево.** Все цвета вынесены в CSS-переменные:

```css
:root {
  --cat-fur:     #E8A05A;
  --cat-stripes: #B5732A;
  --cat-belly:   #F5DCB4;
  --cat-eyes:    #4FA858;
  --cat-nose:    #E07B95;
}
```

Изменение через JS — **одна строка**:

```javascript
document.documentElement.style.setProperty('--cat-fur', '#888888');
```

Можно иметь **сотни** цветовых вариантов без новых картинок.

### Акварельный вариант (когда Алёна нарисует)

**Сложнее.** Каждый цвет — **новый рисунок** или Photoshop hue-shift (качество страдает). Если хотим 5 разных окрасов (рыжий / серый / чёрный / белый / трёхцветный) — это **5 рисунков** базы, плюс позы.

**Решение:** **смешанный** подход — основа SVG (можно перекрашивать), детали-текстуры из акварели (не зависят от окраса).

---

## Уровень 2. Толщина — худощавость

### SVG

**Средне.** Делаем размеры параметрическими:

```css
:root {
  --body-rx: 55;
  --body-ry: 40;
}
```

В SVG: `<ellipse rx="var(--body-rx)" ry="var(--body-ry)" />`. Один JS меняет — кот становится толще/тоньше.

**Важно:** некоторые браузеры не поддерживают CSS-variables в SVG-атрибутах. Альтернатива — через JS манипулировать атрибутами SVG напрямую.

### Акварель

**Сложнее.** Нужны **отдельные** рисунки для разных форм. Можно сделать «тощий / нормальный / толстый» = 3 базовых рисунка, между ними CSS-transitions.

---

## Уровень 3. Пушистость / длина шерсти

### SVG

**Дороже.** Это разные **контуры тела**, не просто цвет:
- Гладкая шерсть → ровный овал
- Пушистая → волнистая граница с торчащими пучками
- Длинношёрстная → ещё больше пучков и хвост пушистее

Реализация — **дополнительные слои** SVG которые включаются/выключаются по флагу:

```html
<g class="cat-fluff" data-level="2">
  <!-- пучки шерсти, видны только при .cat[data-fur="fluffy"] -->
</g>
```

### Акварель

**Так же** — нужны **отдельные** рисунки. Полдня художественной работы на одну форму шерсти.

---

## Уровень 4. Поза (сидит / лежит / прыгает)

**И SVG, и акварель — отдельный рисунок для каждой позы.**

Это **разные геометрии**, нельзя получить одно из другого через transform / variable. Каждая поза = свой SVG-path или своя акварельная картинка.

Сейчас у нас:
- Сидит (статичная idle поза + анимации)
- Прыгает (`acting-play` через CSS-jump)
- Спит (`acting-sleep` — тот же SVG но с закрытыми глазами и Z)
- Гладится (`acting-pet` — счастливые глаза)

Для будущих комнат могут понадобиться:
- Бежит (для Охоты)
- Лежит на спине (финал Охоты — «наелся»)
- Точит когти (для Сада, может быть)
- Прячется (для Подвала)
- Танцует (для пианино)

**Каждая новая поза:** ~1-2 часа SVG-работы или 1-2 часа акварели + сканирование/обработка.

## Стратегические выводы

### Что дёшево менять часто

- **Цвет шерсти** — да, варианты практически бесплатно при SVG. Подходит для «прилагательное-характер» (Барсик-охотник серый, Барсик-эстет рыжий, и т.д.).
- **Размер тела** — параметрически можно. Подходит для стадий роста (котёнок маленький → подросток средний → взрослый большой).

### Что дорого менять часто

- **Поза** — каждая новая = отдельная работа. Закладывать **минимум поз**, переиспользовать.
- **Длина шерсти / пушистость** — нужны отдельные слои или рисунки.

### Решения

1. **Базовая поза одна** (сидит) + **transform-анимации** для всех простых действий (прыжок, дыхание, поворот головы, движение хвоста).
2. **Дополнительные позы только когда необходимо** — например, спит, охотится. Не делать на всякий случай.
3. **Цвет и размер — параметрические**. Это даёт огромную вариативность без новых рисунков.
4. **Когда акварель** — рисовать **по слоям** (тело отдельно от глаз отдельно от ушей). Тогда некоторые слои переиспользуются между позами, а другие подменяются.

## Связь с прилагательным-характером

В `03_progression.md` мы определили что характер кота формируется по стилю игры:
- Барсик-охотник (если охотился много в Охоте)
- Барсик-эстет (если ловил бабочек и сидел у окна)
- Барсик-практик (если кушал червячков, не выпендривался)
- Барсик-сонюшка (если укладывал спать чаще остального)

**Применение:**
- Цвет шерсти — слегка меняется по характеру. Эстет — чуть светлее, охотник — насыщеннее. Это через CSS-переменную (один параметр).
- Размер — слегка меняется. Сонюшка чуть круглее, охотник чуть стройнее.
- Поза `idle` — может быть **специфичной** для характера. Эстет сидит **изящнее**, охотник — **бдительнее**. Это требует **разных** SVG-paths для idle, что **дорого** в реализации.

**Я бы советовала** на старте: характер влияет **только** на цвет и размер (дёшево, видимо), и на **финальное прилагательное под именем**. Не на позу. Это **простой** дизайн с большим эффектом.
