# Стартовая комната

**Это базовый дом зверька.** Сюда игрок попадает первым делом. Сюда он возвращается между приключениями. Эта комната всегда остаётся cozy и простой.

Текущий код: `index.html` (зверёк + кнопка «Покормить»). Постепенно расширяется до полной комнаты по описанию ниже.

---

## Визуальное решение

- 2D, **фронтальный разрез** («кукольный домик»)
- Видна задняя стена, на ней одна-две детали (окно, может полочка)
- Виден пол, зверёк по центру
- Без перспективы, всё в одной плоскости

## Стена

**Не белая.** Тёплый бежевый, мятный или пыльно-розовый. Цвет от которого глаз отдыхает. Не яркие детские цвета.

## Окно на стене — важная деталь

- **Источник света** (меняющегося с временем суток).
- Будущая **точка контакта с миром снаружи**: тень другого зверька, снег, дождь, что-то проходит мимо.

## Что в комнате на старте (минимум)

- Зверёк
- Лежанка
- Миска
- Окно
- Может быть, одна полочка с одним предметом
- **ВСЁ.** Минимализм даёт фокус на зверька.

Комната наполняется **постепенно** — это отдельная петля прогресса (см. ниже «Как наполняется комната»).

## Освещение по времени суток

- **Утро** — мягкий тёплый свет через окно.
- **День** — яркий ровный свет.
- **Вечер** — оранжево-розовый закат.
- **Ночь** — тёмная комната, лампа, луна в окне.

**Технически:** один фон + накладка цветового слоя через CSS overlay. Дёшево и сильно.

```css
/* пример: вечерний overlay */
.room-overlay {
  position: absolute; top: 0; left: 0; right: 0; bottom: 0;
  background: rgba(255, 140, 90, 0.25);
  pointer-events: none;
}
```

JS меняет цвет overlay по `Date.getHours()`. ~30 строк кода.

## Зверёк и взгляд

- **НЕ всегда смотрит в камеру** (будет жутковато).
- Иногда поворачивается и смотрит «на тебя» — при первом открытии за день, после ласки. Создаёт прямую связь.

## Как наполняется комната

Это отдельная **петля прогресса**. У комнаты два механизма наполнения, дополняющих друг друга.

### Механизм 1. Награды за активные действия

**Игрок сам выбирает** что получить. Через мини-игры или активную заботу зарабатывает «очки», тратит их на функциональные предметы:
- Новая миска
- Лежанка получше
- Игрушка
- Аксессуары для зверька

### Механизм 2. Подарки от зверька (главный двигатель возвращения)

**Зверёк сам приносит** игроку вещи. **Игрок не контролирует**, что получит — это **сюрприз**.

Типы подарков:
- Камешек блестящий
- Листик с цветком
- Потерянная пуговица
- Ракушка
- Перо

**Эти вещи бесполезны функционально, но трогательны.** Это **акт общения** — реальные кошки и собаки так делают. Это попадает в глубокую часть памяти у любого, кто жил с животными.

### Откуда зверёк это берёт

Создаём ощущение что у зверька **есть жизнь** за пределами комнаты:

- Из **окна** (которое смотрел)
- Из **«снов»** (отсылка к будущей Комнате Снов)
- Из **секретного выхода** (намёк, не показанный явно)

### Связь подарков с комнатами

Каждый подарок косвенно связан с конкретной комнатой:
- **Листик с цветком** → намёк на Сад
- **Кулинарный ингредиент** → намёк на Кухню
- **Старая закладка** → намёк на Библиотеку
- **Камешек** → намёк на Подвал

Когда у игрока накопилось 5 листиков с цветами — Сад **намекает**, что готов открыться.

### Дневник находок

Отдельный экран — **все находки по порядку**. Не товарный учёт, а **журнал моментов**.

Через год использования там 200+ предметов, каждый напоминает о моменте. Как рисунки ребёнка или открытка от близкого человека: бесполезные, но **дороги**.

Технически: `localStorage` массив объектов `{date, item, room_hint, snapshot}`. Всё клиентское.

## Зверёк живёт своей жизнью между визитами

Когда игрок открывает комнату — застаёт зверька в **случайном** состоянии:
- Спит на лежанке
- Сидит у окна
- Играет с предметом
- Смотрит в твою сторону (rare event)

Это даёт **ощущение присутствия**, не реактивности. Зверёк живёт **в комнате**, не «ждёт твоего нажатия».

**Технически:** массив поз с весами, выбор по timestamp последнего визита + псевдослучайному seed. Дёшево, эффект сильный.
