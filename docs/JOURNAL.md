## 2026-04-30 — Документация структурирована

Раньше идеи лежали в одном огромном `pawmates_рабочий_документ.txt`. Сегодня разнесли по тематическим файлам:

- `00_pillars.md` — неизменяемые принципы.
- `01_architecture.md` — метафора комнат.
- `02_starter_room.md` — дизайн стартовой.
- `03_progression.md` — Bond, петля.
- `04_visual_style.md` — аналоговая графика.
- `05_atmospheric_compass.md` — критерии решений.
- `06_open_questions.md` — нерешённые вопросы.
- `rooms/*.md` — задумки комнат.

Зачем: один файл = одна тема. Когда работаешь над комнатой — открываешь конкретный файл и не отвлекаешься на остальные. Когда добавляешь идею — кладёшь в правильное место, не в общую кучу.
